# 本地数据与录屏隐私

## 录屏模式

控制台顶部“录屏隐私”或悬浮球工具栏 ◒ 可切换。开启后保留粒子、脉冲、客户端名称、事件计数、风险级别、模式和执行结果；隐藏两侧配置/详情区域、原始记录、目标文件名/主机名、真实会话摘要、本地模型和路径线索。工具显示通用类别，会话筛选显示本窗口内的匿名编号，仍能按会话过滤。

隐藏关键参数时不应盲目授权，因此界面暂停新审批、来源定位、模型复核、配置修改和导出。关闭风险提示仍不是批准。退出录屏模式后先核对完整详情，再处理动作。后台检查、已有授权、已提交任务不因录屏模式而停止或撤销。

偏好保存在本项目 .local/presentation.json，只允许管理端修改，其他 Guardian 窗口约在下一次同步时生效；新窗口获取状态前隐藏事件区。请逐个确认要录制的窗口已经显示已隐藏，再启动录屏。离线或同步失败时本窗口保持隐藏；无法保证其他失联窗口同步。损坏的偏好文件默认隐藏，不修改保护规则。

这仅是 Guardian 的屏幕展示模式，不是数据擦除、接口脱敏或系统隐私屏。已进入浏览器内存的事件仍存在，SQLite、本机日志、已下载导出以及其他应用画面不受影响。透明球后的桌面内容仍可能被录下；用黑底预览或录屏工具裁切，避免录到其他窗口。不要把开发者工具、客户端对话或个人桌面一并录制。

## 本地存储与处理

本项目 .local 保存管理/适配令牌、事件 SQLite、模式、偏好和必要运行记录。事件保留最近 2000 条，默认视图最多 200 条。完整工具参数用于当前执行前检查和授权参数摘要，历史仅保存有限脱敏摘要；文件名和目标主机仍可能敏感，录屏前应开启展示隐藏。工具返回扫描仅发送与保存固定扫描元数据，不上传正文。

默认不发送事件到云端。执行前语义实验须明确同意向所选本机 Ollama 处理原始参数；摘要复核仅发送保存的摘要，并可显式选择同会话有限上下文。它们不读取未授权项目内容。Agent 自己的模型供应商和外部访问由其自身配置决定，不能把守卫本地运行宣传为所有 Agent 流量离线。

来源定位的原会话标识、实例关系和可用终端窗口线索只在短期内存中保存，最多 2000 条、24 小时，服务重启失效。不会读取窗口标题、屏幕或命令行。

导出、历史清理和接入配置备份仍应单独管理。清理不是磁盘安全擦除，已导出文件与 Agent 自身历史不会被删除。预览包用白名单排除 .local、用户配置、模型和设计素材，尚未公开发布。
