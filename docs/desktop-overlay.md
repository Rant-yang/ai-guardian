# 原生透明悬浮组件

## 2026-11-02：轨道间星尘

核心与外轨之间加入固定上限 28 个低亮度星尘采样，经投影后裁去侵入核心或越出外环的点。少数亮点带柔光，两处极弱雾团保持透明背景；缓慢漂移与亮度呼吸在减少动效时冻结。按深度分两层绘制，不修改业务事件、抽取粒子或脉冲。这是星尘氛围，不是暗物质的物理可视化。19 项 Node 回归通过。


## 2026-11-02：弥散等离子环

针对硬轮廓铁丝感，轨道不再调用 stroke 绘制亮芯、边线或并行细丝，而使用足够密集、边缘 alpha 衰减为零的径向光斑叠加成连续能量带，亮度和宽度随相位缓慢变化。保持三条轨道原排布及来源节点共享轨迹。删除固定环绕碎点，改为每条轨道最多三颗短命外逸火花；节点尾迹同样使用柔光雾。球面交点亮点和密集双向网格移除，保留十二条柔化起伏涟漪。真实事件流和脉冲逻辑不变，19 项 Node 回归通过；实际视觉待用户验收。


## 2026-11-02：彩色能量球细化

按用户第二次参考反馈增强球体黄白—青蓝—紫色过渡，表面加入随时间旋转的经纬细纹与小型交点亮点，纹理严格裁切在实体球内。光轨采用四层亮芯/柔光与两条邻近细光丝，轨道碎光保持有界，不扩散成点阵笼罩。核心放大暖色辉光及短射线，来源小球发光增强。新增悬浮工具栏“◐”切换透明与黑底预览；默认透明，黑底模式附少量静态远星。该模式仅影响展示，不改变监控、权限或事件计数；不宣称真实 OC 渲染、景深后处理或 8K 输出。


## 2026-11-02：参考图光轨重构

依据用户提供的组件风格参考图，移除 440 点球壳、球面经纬线和独立八字轨迹，改为三组倾斜圆形三维光轨（投影为椭圆）。光轨与五个来源节点共享 orbitPoint 几何，避免小球脱离轨道。光轨采用微弱宽辉光和清晰细光线，少量装饰光珠沿环运行。前后半轨、拖尾和节点分层绘制，由实体核心遮挡后方。核心改为白金能量焦点、短光芒与青蓝紫暗面，保持透明背景。真实动作粒子抽取、吸收脉冲、风险弹窗逻辑保留。19 项 Node 回归通过；实际视觉仍需用户在桌面确认。


## 2026-11-02：立体来源节点与轨道拖尾

来源节点改为约 5px 基础半径的实体球面着色，保留来源颜色，加入偏心高光、暗面与边缘反光。轨迹尾迹采样约 3 秒、36 段，使用柔光外层与渐细亮色内层；依据每段深度拆分前后绘制，背部受核心遮挡。减少动效时不绘制尾迹。真实事件触发的粒子抽取、吸收脉冲与风险提示保持原有行为。19 项 Node 回归通过，测试不等同于像素观感验收。


## 告警详情跳转修复

旧桥接方法 `console` 与 pywebview EdgeChromium 内部日志通道同名，调用只打印参数，不执行应用方法，也不返回 Promise。已更名为 `open_console`。告警按钮携带当前 event_id，在独立原生控制台窗口使用一次性票据连接并定位事件；再次点击复用窗口。窗口激活通过 WinForms UI 线程执行。打开失败展示错误，打开详情本身不提交审批。事件超出最近 200 条时显示无法定位提示，不能把另一条事件当成目标。

18 项 Node 测试通过。原生 smoke 使用已有记录，经页面按钮和实际桥接验证 `detail_window_connected=true`、`detail_event_matches=true`，未创建检查事件、未授权、未重试动作。


## 接入节点轨道

五个来源节点具有各自相位、速度、方向与倾角；OpenCode / MCP 使用八字轨迹，其余使用椭圆轨迹。节点保留固定来源颜色，附带短尾迹和随深度变化的大小、亮度，背面节点先绘制并被实体核心遮挡。已移除三个无业务含义的装饰卫星和固定辐射连线。节点巡航只是待机动效，不代表客户端在线或产生调用；真正的汇入粒子仍只由新事件触发，从当时的节点位置发射，已发射的路径不随节点移动而跳变。关闭动效或系统要求减少动效时节点固定且不画尾迹。


## 2026-11-01：灰底与球体纵深修正

此前负边距扩展整个窗口的 DWM glass 虽然保留输入，却在用户实机上出现灰色底板。本次重置扩展边距，明确关闭系统 backdrop，启用空模糊区域的 alpha 合成；仍不使用颜色键或整窗降透明度。实现参考 [GLFW 的 Windows 合成处理](https://github.com/glfw/glfw/blob/master/src/win32_window.c) 的 API 使用方式，未引入其运行库。系统背景选项参见 [Microsoft DWM_SYSTEMBACKDROP_TYPE](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwm_systembackdrop_type)。Windows 11 的禁用 backdrop 调用在本机成功；旧系统不支持该选项时仍使用基础合成路径。

球体修正负 z 为近处的透视关系，背面点云、轨道和卫星先画，由不透明实体球遮挡，再绘制正面几何。核心增大，点云更贴近球面；定向高光、暗部与紫色边缘反光强化体积，背景光晕缩小到局部。使用 Canvas 2D 投影三维几何，不宣称 WebGL 渲染。

15 项 Node 回归通过；原生 smoke 确认合成 API 成功、系统背景关闭、自动连接、拖动、三个筛选命中与告警展开均正常。这不是像素透明度或人工视觉验收；最终观感仍需实际桌面确认。下方旧版 DWM glass 描述已由本段替代。

## 2026-11-01：球体常驻与风险弹窗

桌面组件默认只显示 3D 核心、轨道和来源粒子，不展示通过检查的动作列表。空闲请求尺寸 360×330；发现启动后新发生的真实 `warn/review/deny` 事件时展开为 360×510，显示风险卡片。收起卡片不批准、不拒绝动作；审批仍在完整控制台处理。多个风险逐条查看，组件队列最多保留 20 条，完整记录在控制台。断线提示保留。鼠标移入时才显示三个筛选和窗口按钮；筛选作用于随后收到的粒子流，不重放历史流量；风险提醒独立覆盖所有接入客户端，避免筛选隐藏风险。

来源配色：Claude 冰蓝、OpenCode 紫、Gemini 玫红、MCP/演示金、Ollama 薄荷绿。流量从来源节点汇入核心，长拖尾、三层倾斜轨道、分色点云与吸收脉冲增强视觉。颜色代表来源，不等于安全结论；拒绝同时使用红色核心脉冲和文字风险卡片。未发生调用的来源不会自动发射粒子。桌面真实视图不混入 MCP 合成演示事件。

启动前历史事件不弹窗；关闭提示后同一事件不会重复弹出。新事件到达最多受正常约 1.5 秒刷新间隔影响，断线恢复遵循退避策略。缩小动效偏好仍受支持。下文五条事件卡片是上一版记录，当前行为以本段为准。

## 视觉与操作

- 请求窗口尺寸 360×450；实际逻辑尺寸受 Windows DPI 缩放影响。本机实测网页视口 346×413。
- 透明底层，上方 3D 粒子核心，下方五条深色半透明事件卡片。桌面透出区域与卡片区域分开，保证文字对比度。
- 事件、客户端、会话筛选保留并排一行；不显示标题、在线标语、模式文字栏或原控制台背景面板。
- 拖动粒子区域移动窗口。鼠标进入窗口时显示三个小按钮：打开控制台、切换置顶、关闭。关闭只关闭组件，不停止后台或 Agent。
- 默认置顶；组件单实例，重复启动不会堆叠多个悬浮窗。
- 粒子流只由新检查事件触发，空闲时为核心待机动效；不会为了视频效果伪造事件。断线时清除流量动效并显示短提示。
- Windows DWM 扩展透明合成区域，取消颜色键透明，保留宿主鼠标命中；不使用整窗低不透明度。当前不提供桌面毛玻璃模糊、全区域鼠标穿透或 OBS 采集兼容保证。

## 技术与验证

入口 `guardian/desktop.py`，启动脚本 `scripts/open-overlay.ps1`，页面 `/overlay`。使用短期单次票据连接，不在 URL 存储管理令牌；原生桥只开放关闭、置顶、打开控制台三个固定操作。导航限制在本机 `/overlay`。运行日志存入 `.local/desktop.log` / `.local/desktop.error.log`。

40 项 Python 基线回归、14 项 Node 回归通过。原生启动验证确认：自动连接成功、无边框/置顶开启、颜色键关闭、网页背景透明、三个筛选同排、五条事件不超出视口。补充交互检查：粒子区和三个筛选的 Windows 鼠标命中均属于组件自身，页面内模拟拖动消息使原生窗口实际移动，三个筛选的 DOM 命中没有遮挡。正在使用会话筛选时暂缓重建选项。验证结果为 `.local/desktop-status.json`，后续 smoke 交互报告写入 `.local/desktop-interaction-test.json`。这些检查不等同于人工鼠标下拉操作或像素级视觉验收。

修复原因：旧版设置 `TransparencyKey`，会把透明区域的鼠标操作传递给下层窗口，参见 [Microsoft TransparencyKey 文档](https://learn.microsoft.com/en-us/dotnet/api/system.windows.forms.form.transparencykey)。修复改用 [DwmExtendFrameIntoClientArea](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/nf-dwmapi-dwmextendframeintoclientarea) 合成方式，保留输入区域。

本机安装源码确认 EdgeChromium 的透明背景实现；[pywebview API](https://pywebview.flowrl.com/api/) 中部分 Windows 透明说明与此安装版本不同，因此以本机测试及实际体验为准。
