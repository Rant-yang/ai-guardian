# 事件快照回放

在完整控制台选择演示/真实接入、客户端、会话和风险筛选，再点击“回放当前筛选”。范围限最近 200 条观察台数据，开始时冻结一份本页内存快照；不会创建新的检查事件，也不会执行命令。

- 默认暂停在第一条；点击播放或下一条。
- 支持 0.5×、1×、2×、4×；按事件发生时间排序。
- 原始相邻间隔限制在 0.2～3 秒，再按倍速播放；不是严格的原始墙钟时间复现。
- 粒子抽取和脉冲随回放事件触发，明显显示 REPLAY / 历史快照。
- 页面隐藏或检测到超过两秒的计时中断时暂停，避免休眠后突然跳过整段。
- 退出恢复当前实时数据；新实时事件不会混入快照或触发回放粒子。

回放期间控制台修改接口被禁止；审批、来源跳转、模型复核和用户反馈入口只显示只读说明。开始回放前已经提交的请求不被撤销。其他实时窗口及后台保护继续独立工作；当前页服务失联时会明确显示连接中断，内存快照仍可播放。

每条记录包含开始回放时保存的最终决定/回执/反馈，而不是这些字段在过去每一时刻的变化日志。不要把后续回执的快照显示解释为动作发生瞬间就已确认成功。

当前回放只在完整控制台提供，桌面悬浮球仍用于实时监控。跨机器导入回放、历史全量回放、逐阶段状态时间线、内置视频录制尚未完成。现有脱敏导出只用于分享元数据，尚不是可重新导入的回放文件。
