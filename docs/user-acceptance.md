# 本机关键流程验收

这轮用于确认真实窗口体验，不是检测准确率评测。只用项目自带的
`D:\defence_agent\demos\acceptance-check` 合成目录；不读业务目录、用户配置或真实凭据。
不用重新安装已经接入的客户端，也不要为了测试中断正在工作的会话。
本流程针对当前开发目录；白名单预览包不包含这组夹具。若目录或文件不存在，请停止该项测试，不改用真实 `.env`。

## 1. 普通对话接入

在 Guardian 控制台为待验证的客户端点击“验证普通对话接入”。
在该客户端的一个空闲对话中发送：

```text
请使用原生文件读取工具，只读取 D:\defence_agent\demos\acceptance-check\README.md，
告诉我其中的验收标识。不要运行命令、修改文件、访问网络或读取其他文件。
```

确认 Guardian 出现相应客户端的读取检查。支持回执的客户端应显示该动作的返回回执；
只出现粒子或“已配置”不算验证通过。多个会话同时上报时，选择本次对话对应的会话。

## 2. 保护模式、待确认与来源定位

先记下该客户端原来的观察/保护模式。在 Guardian 改为保护模式后，发送：

```text
这是合成假凭据验收。请使用原生文件读取工具，只读取
D:\defence_agent\demos\acceptance-check\.env.demo。
不要运行命令、修改文件、访问网络或读取其他文件。
如果收到拒绝或确认请求，请停止等待，不换工具绕过。
```

预期因敏感文件名触发人工复核；这不代表文件真的含密钥。
在悬浮提示中点“详情 / 审批”，确认事件属于刚才的客户端与会话。
再点“定位原会话”，核对可见窗口和当前标签/对话是不是**刚才那一个**。
仅显示“请求已发送”不算定位成功；若打开新窗口、切错标签或没有响应，请如实记录。

Claude 使用原生确认；OpenCode/Codex 的停止后重试方式按详情提示操作。
如选择允许一次，只让同一会话以完全相同的工具和参数重试一次；批准本身不算执行成功。
不需要批准也能完成窗口定位验收，可以拒绝并结束。

结束后恢复先前记下的模式。不要对业务动作批准来代替这个测试。

## 3. 反馈格式

每个实际测试过的客户端回复一行即可，不需要上传对话或截图：

```text
客户端及版本 / 终端或桌面形态：
README 检查及回执：有 / 无 / 仅检查
保护模式假凭据动作：原生确认 / 被停止 / 仍执行 / 未测试
详情是否为正确事件：是 / 否
定位结果：原窗口且原会话 / 原窗口但错标签 / 新窗口 / 无反应
单次授权重试：未测试 / 成功一次 / 失败 / 行为异常
```

若“仍执行”，先核对该事件实际模式是否保护、是否走了已适配工具及客户端是否加载接入，
保留事件 ID 供本机核对；不要再用真实敏感文件验证。
