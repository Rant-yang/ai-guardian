## 仍需推进的主要链路

1. **本地语义效果与实时性。** 现有 Qwen3:8b 在 1.5 秒预算内无法有效完成判断。固定挑战样例暴露未知脚本/授权范围缺失时的过度自信；新增提示词无收益已撤回。实验通道不会把 no_additional_signal 当成任务授权，默认仍关闭。事后复核支持单次人工补充说明和摘要引用核对，但不能替代自动可信上下文或独立效果评测。更小候选模型下载尚待用户确认；不把待确认当作授权。
2. **告警到原始窗口。** Guardian 详情定位已验证；Codex 协议和 OpenCode 会话请求不等于可见窗口已正确前置。Claude 新增唯一祖先终端前置尝试，尚未完成真实终端/标签页验收，仍保留手动恢复方式。用户期望的统一原窗口体验未完成。
3. **新用户安装与长期运行。** v29 中文路径独立虚拟环境完整安装与重复复用通过，v30 独立副本通过 207 项 Python、65 项 Node 与隔离 HTTP 烟测；8 个桌面依赖版本已固定并逐项核对，但不是全新 Windows 验收或带哈希签名的供应链锁定。撤销保留接入后新增的用户配置、目录链接检查已有隔离测试。旧基线及冻结 v15 两小时 HTTP/SQLite 验证均完成；不覆盖其后版本，也不等于 GUI、休眠、低资源或多屏验证。桌面三分钟 CPU/句柄采样稳定，旧窗口工作集之和约 816–821 MiB（含共享页重复计数），仍需分析。紧凑窗口已停止构建隐藏详情并采用字段投影，本机 200 条事件响应减少 61.6%；尚无同条件内存改善证据。
4. **研究增强能力。** FR14 录屏隐私模式与已有回放已实现，原生可见文本遮挡已验证，完整录制采集仍需用户验收。FR13 已增加只读同会话证据与可选有界相关摘要复核（见 investigation.md），仍缺独立真实模型效果验收和检测器编排；FR16 自定义策略、FR17 内部模型增强、FR18 完整双语仍未完成。当前不是完整自主调查助手。原文允许不同时实现全部 P1，内部探针没有增益证据时应保留实验性质。
5. **后续范围。** FR19 安装前扫描、FR20 更多平台/记忆等为原文 P2；未经确认不将它们冒充已实现。云端增强尚无完整配置与授权流程。品牌、许可证及公开发布仍需用户确定。
