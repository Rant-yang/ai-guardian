# 本地事件复核（实验能力）

在真实事件详情中点击“发现本地 Ollama 模型”，选择模型，再点击“确认发送摘要并复核本次事件”。该操作需要管理权限。扫描仅查询回环地址 11434/11435 上已安装模型，不下载、不改模型配置、不调用云端 API。

这是按需的有界调查组件：输入只有数据库中已保存的工具名、脱敏动作目标、规则命中及解释、模式和执行状态，不包含原始命令、文件全文、会话标识或凭据。模型无法看到完整参数和用户授权，可能只能回答上下文不足。它不等于执行前语义防火墙，也不证明动作安全。

结果单独保存在事件的 model_review 字段，可能是排队、运行、完成、失败或中断。模型只能输出固定的风险分类与评估枚举，不接受自由文本命令或授权。复核不改变规则决定、单次授权或执行回执，不会自动重试工具。

资源预算：一个后台 worker，最多两个排队任务；模型请求最多等待 120 秒以容纳冷启动，其他元数据请求各 3 秒；请求模型在最后一次复核后驻留最多约 5 分钟以避免反复加载（由 Ollama 实际调度）；最多 12,000 字符脱敏上下文、2,048 模型上下文 token、160 输出 token、64 KiB 响应。超时或结构无效显示失败，服务退出/重启将未完成复核标为中断。相同事件正在复核时不会重复提交。可取消单个排队或在途复核：排队任务释放容量，在途请求关闭本次连接并丢弃迟到结果；这不等于确认 Ollama 已立即释放显存，也不会取消 Agent 的动作。请求截止时间覆盖整个响应读取，慢速分段响应不能无限延长等待。

当前仅选择具有本地权重大小信息的模型，过滤 cloud 标识及 remote_host/remote_model；请求前再检查模型元数据。拒绝 HTTP 重定向并禁用系统代理。对恶意伪装的本机模型服务不提供强隔离保证。只向你信任的本地 Ollama 发起复核。

可复现合成验证：

```powershell
python scripts/verify_local_review.py --port 11434 --model YOUR_LOCAL_MODEL --runtime cpu
```

不读取真实事件，不执行模拟命令；输出保存至 `.local/local-review-verification.json`。该检查验证推理链路及判定/审批不被改变，不能用两条样本宣称检测有效率。

若使用独立 Ollama 实例，可运行 `scripts/start-ollama-demo.ps1 -ModelDirectory "你的现有模型目录"`；只启动 11435 端口进程，默认目录来自 OLLAMA_MODELS 或用户目录，不再包含开发者机器路径。

接口依据：[Ollama 结构化输出](https://ollama.com/blog/structured-outputs)、[Ollama API 源文档](https://github.com/ollama/ollama/blob/main/docs/api.md)。使用 JSON schema 限定返回格式仍不能保证模型判断正确，本项目另行验证枚举与字段，并保持模型建议和执行权限分离。


## 本机兼容验证（2026-11-02）

Ollama 0.40.13 / qwen3:8b / Windows：自动设备模式在 GPU 预热处多次超时；CPU 兼容模式两条合成样例分别约 15.1 秒、8.0 秒完成，规则决定和审批状态未变。证据为 `.local/local-review-verification.json`，历史失败证据为 `.local/local-review-cold-verification.json`。这是单机两条样例的链路验证，不是稳定性或检测准确率评估。GPU 路径未修复，不能推广到其他机器。

界面可选 CPU 兼容模式，按本次请求设置 `num_gpu=0` 和 8 个线程；不写 Ollama 全局设置。模型分类始终标为“模型推测（未验证）”；当前上传样例中曾出现无充分依据的注入分类，效果评测尚未通过。

参数来源：[Ollama Runner 请求参数定义](https://github.com/ollama/ollama/blob/main/api/types.go)。


### 模型资源忙碌

摘要复核与语义预热、执行前语义检查及模型演示共用守卫服务内的一个模型资源锁。其他通道正在使用时，本次摘要复核记录 local_model_busy，不调用模型、不改变动作决定或批准状态；界面提示稍后手动重试。取消、异常和返回结果后释放资源。复核的元数据查询和推理共用 120 秒总预算，输出被截断时不采用。

运行复核或模型演示会让语义通道的原准备状态失效，避免把被其他任务替换的驻留模型当作已预热。此互斥只管本服务，不能证明外部 Ollama 请求或显卡任务不存在。

新增可选同会话相关摘要范围，默认仍为单事件。范围、清理取消与真实模型局限见 [investigation.md](investigation.md)。
