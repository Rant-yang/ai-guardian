# 有界相关动作调查

## 单次补充任务说明

事件详情的本地模型复核区可填写“这次要做什么、允许的范围”，再点击“确认发送摘要和任务说明并复核”。默认不填写、不发送；服务单独检查 task_context_confirmed=true，最多 2000 UTF-8 字节（中文通常每字 3 字节）。发送原文给所选本地 Ollama，不自动脱敏，请勿填写凭据。此说明只绑定所选事件的本次复核，不成为规则授权、任务级白名单或自动恢复依据，也不传给执行前实验。

Guardian 仅在队列/请求内存中使用正文，事件历史只保存 task_context_provided 标记；禁止将说明作为结果证据引用。结果仍限制为枚举和原本脱敏事件字段的逐字引用，原规则决定、审批和回执不改变。无法承诺内存取证擦除或 Ollama 自身不留日志；后者取决于其配置。

切换事件、进入回放或开启录屏隐私会清空该输入草稿；成功提交也清空，失败时可检查后重试。输入获得焦点期间普通刷新不重建文本框，避免打字被打断。输入不使用浏览器持久化存储，不自动沿用到其他会话。

新增合成复现选项：`python scripts/verify_local_review.py --port 11435 --model qwen3:8b --runtime cpu --related --task-context-fixture`。两例固定说明的本机验证耗时 47063 ms、35781 ms，均完成但缺有效引用而降为上下文不足，原判定和审批未变。报告 .local/local-review-task-verification.json。只证明输入和保守结果链路，不证明模型有效性提升；自动可信任务捕获、低打扰保护仍待实现。

从真实事件详情点击“查看相关动作证据”。服务只读取该客户端、该会话、截至所选动作之前 15 分钟内仍保留的记录；最多展示 8 条、16000 字节脱敏证据。顺序按守卫入库顺序，时间采用守卫记录时间；不跨客户端拼接，不加入此动作之后的新事件。最多查看保留库中的 2000 条，不能声称完整会话轨迹。

证据保留动作摘要、执行前决定、执行回执、返回扫描元数据与时间。界面明确显示缺少回执、返回扫描不可用、扫描截断和范围预算。快照读取不发起模型调用或 Agent 动作，不修改审批；快照不是当前授权状态，当前审批仍在独立控件处理。切换事件或进入回放丢弃界面快照，过期异步响应不会覆盖另一事件详情。

可选的本地模型复核增加范围选择：默认仍为当前动作。用户选择“同会话近期相关动作”并点击确认后，以提交时的快照为准，最多 8 条、6000 UTF-8 字节；优先保留当前动作和最近前序事件，超预算明确记录。模型结果保存采用的事件 ID、条数、快照时间及截断标记，结果只提供结构化风险类别和不确定性，不产生执行指令。

沿用固定回环 Ollama 端口、已安装本地模型校验、资源互斥、两项等待队列和每次运行 120 秒总预算。相关复核使用 8192 token 上下文配置与最多 480 token 输出（为证据引用留出空间）；这些是请求上限，不保证本机模型达到实时速度。没有联网取证、任意文件读取、工具调用或自主重试循环。检测器编排尚未实现，当前不是完整自主调查 Agent。

每个非“上下文不足”的模型风险类别必须引用发送快照中的一条记录、一个白名单字段及其单个字符串内 4–96 字符的原文。字段限动作摘要、规则线索、规则解释、工具返回扫描元数据；服务按提交时的快照逐字核对，不去读取更新后的记录。索引越界、引用缺失、编造原文、分类无引用、无风险却声明 concern 等情况统一降为 uncertain / insufficient_context，不保留无效引用和原风险分类。结构无效或生成截断则复核失败。有效引用展示在详情中；旧结果明确标为未核对引用。

逐字匹配只证明这句话存在，不能证明它支持风险判断，更不能证明因果关系。模型仍可能引用普通读取来推测注入；这需要独立效果评测解决，当前校验不会冒充语义验证。引用仅来自原本脱敏的摘要，不增加原始参数、文件内容或用户对话上传。无论结果如何，原决定、审批与回执都不改变。

历史清理与提交使用同一复核锁；清理快照包含的任意事件会取消等待中的相关复核，即使所选主事件仍保留。运行中也丢弃后续结果，不保证 Ollama 立即释放模型资源。过往已完成的模型复核是历史结果，不自动重新判断。

调查材料仍是不可信数据。先后出现不证明注入导致外传；没有用户任务、完整命令或文件正文时必须保留上下文不足。模型不能批准动作或修改保护规则。云端调查未实现。
