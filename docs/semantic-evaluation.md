本地原始报告：`.local/semantic-evaluation-baseline.json`、`.local/semantic-evaluation-v2.json`。报告只存样例 ID、预期标签、枚举结果、模型摘要及耗时，不存工具原文。开发样例本身在脚本中可检查。

复现：

```powershell

```

候选检查端口、已安装本地模型及 remote 标志；输入有字节上限，元数据与推理共享总截止时间。异常、超时、输出截断或格式错误均不产生低风险结论。候选只返回评估，不修改判定、授权或执行状态。

## 有界执行前实验通道

四个原生适配器检查入口共用该通道，合成演示不调用它。只读工具暂不路由；已有规则拒绝或审批直接采用规则决定。其他选中客户端的动作可进入本地模型检查，最多一个并发，不排队，预算 1.5 秒，为现有 3 秒客户端超时留出余量。

模型 concern/uncertain、繁忙、超时、超预算或无效输出进入 review；保护模式沿用客户端原生确认或守卫一次性批准后重试，观察模式仍只告警。由于模型未获得可信的用户任务授权上下文，现在 no_additional_signal 也进入 review，并保存 review_reason=missing_task_authorization。它不能补足授权、覆盖规则拒绝或声明安全。规则已有明确决定、只读跳过、未选中客户端和默认关闭路径保持原行为。这意味着显式开启实验后，所有进入模型检查的动作都需要确认，不能把这项保守限制当成低打扰智能检测已完成。界面开启前说明这一代价。

管理接口 `POST /api/semantic/config` 接受 enabled、confirmed_raw_local_processing、clients、port、model。启用须明确确认原始工具参数将发给所选的本地 Ollama（区别于脱敏摘要复核）；适配器令牌无权配置。配置仅存当前服务内存，重启关闭；模型不自动下载。控制台“执行前语义实验”提供发现模型、选择客户端、预览处理范围及明确确认；不会自动勾选或启用。

配置修订绑定一次性授权，修改配置或服务重启后旧授权不能在新语义策略下复用。检查期间配置变化会明确请求重新核对。参数只在调用期间驻留内存，事件仅保存枚举状态、类别、耗时和模型摘要，不保存参数或模型名称。摘要复核、语义预热、执行前检查和模型演示共用同一服务内的模型资源锁；忙碌时不新增模型请求。其他模型任务可能切换驻留模型或设备，因此会让原预热状态失效。这个限制不覆盖其他进程直接调用 Ollama。

实测脚本 `python scripts/probe_semantic_gate.py` 使用独立内存数据库与临时回环端口。本机 Qwen3:8b 返回 timeout，HTTP 全程 1516 ms，保护决定 review；样例命令执行数 0，真实服务配置未改变。结果保存在 `.local/semantic-gate-probe.json`。这证明超时降级链路，不证明模型在实时预算内有效检测。

验证：122 项 Python 全套、34 项前端及适配器测试通过。默认本地语义检测门槛仍未达到；下一步需更快候选/预算优化、真实任务上下文与独立效果验证。


## 预热与运行设备验证

新增独立合成预热，不用真实工具动作承担冷启动。开启配置后需要在控制台点击“用合成输入预热”；后台单并发、60 秒预算，发送固定合成数据，不执行工具或下载模型。预热、动作检查共用本通道并发槽；关闭实验、修改配置和关闭服务会取消预热并丢弃迟到结果。四分钟没有成功检查后，准备状态过期；未准备好时立即请求人工确认，不再次加载模型。运行方式可选 CPU 或自动设备，均为单请求配置。
