# 安装维护与退出使用

## 首次运行

1. 将完整项目解压到一个准备长期保留的目录，不要直接在压缩包中运行。
2. 双击 Install.cmd。当前需要 Python 3.11–3.13 和 WebView2；缺少时按安装提示补齐再重试。
3. 控制台扫描并选择客户端，核对预览后确认。只对已实现适配器提供接入。
4. 在对应客户端重新加载，完成其要求的信任确认，再做普通项目文件读取，并使用“检查接入是否生效”核对新事件。
5. 默认陪伴观察只提示，不阻断。严格保护是单独选择，服务故障时可能阻止动作。没有事件不代表安全或全部窗口已接入。

## 桌面打不开

双击 Check.cmd 进行离线配置诊断。它不启动服务、不执行第三方命令、不修改客户端设置。没有兼容警告不等于所有 Hook 都能正常运行。

安装不完整时重新运行 Install.cmd。端口冲突时不要结束未知进程，先关闭自己已打开的另一份 Guardian。启动错误记录位于 .local/launcher-error.log；不要公开整个 .local，其中包含令牌和行为记录。

## 更新与移动目录

当前没有自动升级器。以下是保守的更新流程，而不是已完成的一键迁移：

1. 保存 Agent 工作并退出客户端，在旧项目运行 Disconnect.cmd，核对并确认撤销。出现冲突或失败时保留旧目录，先处理问题。
2. 关闭 Guardian 窗口，在旧目录运行 scripts/stop-background.ps1 正常停止后台；失败时不要直接删除目录或强杀未知进程。
3. 将新版本放入新目录，运行 Install.cmd，再选择客户端接入并验证。新安装默认观察。
4. 旧事件记录和备份留在旧目录；不要复制 .venv、令牌、PID 或整份 .local 到新目录。当前尚无跨安装历史导入功能。

如果已经移动了项目，优先恢复到原目录再撤销。陌生入口或改动过的脚本不会被自动覆盖，避免误删其他工具的配置。不要同时保留两个有效的接入入口。

## 完整退出使用

1. 保存工作、退出 Agent，双击 Disconnect.cmd。
2. 预览只涉及当前环境变量指向的用户级配置。输入 REMOVE 才执行；取消不修改配置。项目级配置、其他系统用户或其他安装目录需分别核对。
3. 有失败或冲突时不要删除项目。已撤销项不会为了失败项被自动恢复。
4. 关闭 Guardian 窗口，运行 scripts/stop-background.ps1。重新启动 Agent，验证正常读取和写入。
5. 如需保留历史，先保留原目录或通过控制台脱敏导出。确定接入已撤销、进程已停止且数据不再需要后，才手动删除项目目录。

客户端配置旁的 guardian-backup 文件保留作恢复用途，可能包含原有敏感设置，请自行保管。不要用整份旧备份覆盖已有新设置；这可能丢失用户后续修改。

## 发布前仍须完成

- 干净 Windows 的首次安装与卸载验收，包含缺依赖、断网、中文路径和重复安装。
- 每款支持客户端的实际版本矩阵及真实会话测试，不能以协议测试代替。
- 可靠返回来源窗口、多屏和休眠恢复、当前版本长时运行。
- 项目许可证、第三方许可核查及正式发布版本确定。

目前的打包产物仍标记为本地预览，不因维护入口完善而自动升级为正式发布。
