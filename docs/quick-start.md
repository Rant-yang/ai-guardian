# 快速体验

现有安装：双击项目 `Guardian.vbs`，控制台自动连接本地服务；点击桌面悬浮，或双击 `Guardian-Overlay.vbs`。无需为新向导重新安装当前能用的接入。

首次安装：双击 `Install.cmd`，或在项目目录执行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1`。需要 Python 3.11–3.13 和 WebView2，脚本使用项目内独立环境。完整要求见 [README](../README.md)。

安装脚本优先复用项目环境，其次检查 PATH；若未找到受支持 Python，再只读枚举 Windows Python Launcher 已注册的版本。无需仅为守卫手动调整 PATH；未找到可用版本时会停止并提示安装。该枚举不会下载 Python，也不会更改系统默认版本。可先运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1 -CheckOnly` 检查 Python/WebView2 前置条件；通过不代表依赖安装、桌面启动或 Agent 接入已经验证。

控制台默认显示真实接入。尚无真实动作时，可直接点击事件区的“扫描本地客户端”；演示需主动切换视图或点击运行演示，不会在打开页面时自动启动。已有动作但被筛选隐藏时，会提示调整筛选。

1. 在控制台扫描本地客户端。扫描不会写配置。
2. 勾选 Claude Code、OpenCode、Codex 或 Gemini 中需要接入的项目。
3. 预览全局接入，核对目标文件，再确认。已有接入保留；新增配置不替换模型/API/其他插件。
4. 重启对应客户端，完成客户端自身的信任提示。
5. 点击向导末尾的“检查接入是否生效”，为本轮配置成功或保留已有接入的客户端一起开始验证；失败项不会计入。页面自动滚动到验证提示词和状态，再向各客户端普通对话发送页面给出的只读 README 提示词。也可在单个接入卡片点击“验证普通对话接入”。页面核对验证开始后的真实读取和同一动作的回执；点击“查看本次验证动作”可核对详情。旧记录、演示和其他客户端不算本轮证据。配置成功不等于已收到真实动作。
6. 日常桌宠体验推荐“陪伴观察”：后台在线时监控动作、提示风险，不由守卫阻断操作；后台关闭时 Agent 按自身权限继续工作。只有需要强制拦截时才选择“严格保护”，并确认离线影响：后台未启动或失联也可能阻断读写。严格保护不是使用悬浮球的前提。

如果 Claude 提示 `Guardian unavailable; protection failed closed`，表示严格保护的检查未完成，并不表示 Claude 的文件权限被破坏。启动 Guardian 后，在客户端模式中保存“陪伴观察”；下一次工具检查采用新模式，被拒绝的动作需要重新发起。关闭网页或悬浮球仅关闭界面，不等于停止后台或撤销全局 Hook；需要完全解除接入时使用下方撤销流程。

悬浮球正常时保留轨道、粒子和脉冲效果；风险弹窗可打开 Guardian 事件详情。目前尚不能准确跳回原始 Agent 对话窗口。不支持原生暂停恢复的客户端，单次授权后需要重新发起动作。

若悬浮状态显示“显示缺口待核对”，表示同一次服务运行中两次刷新之间，最近 200 条记录已完全换新，可能有动作没在这个窗口展示。请在控制台查看或导出保留的历史核对；这不等于后台漏检或防护失效，也不证明缺口中存在风险。提示保留到页面重新加载，不能仅因恢复连接就假装展示已连续。历史本身也有保留上限，不能保证找回所有过往动作。

撤销接入：重新扫描、勾选客户端，预览撤销并确认。只删除本项目接入；文件被其他程序改动或计划过期时须重新预览。多客户端处理可能部分成功，界面逐项报告结果。

后台停止脚本现在要求与本项目匹配的启动身份记录（PID、进程创建时间、解释器和项目目录），避免 PID 复用时误停其他进程。较早版本启动的服务只有 PID 记录时，会拒绝自动停止并提示人工核对；不要把其他目录的身份文件复制过来或手工伪造。下次由新版启动脚本创建后台时会自动生成记录。关闭悬浮窗仍只关闭桌面窗口，不等于撤销客户端接入。

若启动提示无法保存启动记录，本次新建后台会被停止。检查本项目 `.local` 的写入权限和同名路径冲突后重试；不要通过结束其他程序来释放端口。此错误不表示 Agent 已接入，启动成功后仍需完成真实动作验证。

接入验证不会自动启动客户端或发送提示词；通过一次读取验证也不等于所有窗口和工具均受保护。验证只留当前页面内存，服务重启或动作超出最近 200 条列表时需要重新验证。客户端报告失败或被停止会分别显示，不会当成成功。

若同一轮刷新发现同客户端多个会话的读取，验证先展示会话摘要与动作时间，要求选择刚发送提示词的会话，再绑定该动作回执。选定后可查看本次验证动作详情。发现过多会话后不会因列表暂时只剩一个候选就静默代选。单会话先到时仍采用该读取，不能据此证明它就是指定窗口或 README；请核对动作详情。没有读取对话内容或自动发送验证提示词。

暂不上传 GitHub。录屏前检查画面中是否包含真实路径、提示词或其他个人信息；宣传只描述实际验证过的能力。


### 确认接入实际生效

“验证普通对话接入”只接收启动验证后两分钟内的新读取检查。超过窗口没有匹配动作时结束该轮，修复客户端信任或配置后重新开始；不会把很久以后的另一条动作补算为成功。已绑定的读取只等待它自己的回执。

模式切换后，若最近实际检查仍为旧模式，状态显示“新模式待实际检查确认”，需重新发起读取。没有常驻心跳的客户端超过五分钟无动作时显示“近期无动作”，这不等于掉线。Gemini 当前只有执行前适配，显示“仅执行前检查”，不会等待尚未实现的关联回执或把缺失回执判作执行失败。

扫描支持 OpenCode 的全局 JSON/JSONC 配置线索及已存在的本项目插件文件，也检查 Windows APPDATA/LOCALAPPDATA 重定向后的固定安装位置。某个候选路径不可读取时仍保留其他有效结果，并提示检测不完整。配置线索只检查文件存在，不读取正文；发现文件不证明客户端已安装或钩子已生效。扫描不是全盘搜索，独立终端中的环境变量和自定义安装目录仍可能需要人工核对。

更新项目后，OpenCode 若提示“在线实例需加载新版”，表示至少一个在线实例没有上报当前适配器标识。完成该窗口手头任务后重启对应 OpenCode，再做读取验证；无需为了插件升级覆盖模型或 API 配置。全局入口文件正确不代表已运行实例加载了最新模块，心跳版本也不等于工具防护已实测通过。
取消接入使用控制台的“预览撤销接入”，核对文件后确认。撤销只移除当前安装所拥有的守卫钩子，不用旧备份覆盖整个配置，因此接入之后新增的模型设置与其他钩子会保留。OpenCode 专用插件若被修改会拒绝自动移除，先人工核对。已运行的客户端可能仍加载旧插件，需要重启相应客户端才能确认撤销生效。

控制台与独立安装脚本都拒绝配置路径中的符号链接/Windows 重解析目录及超过 2 MiB 的配置文件，遇到这种布局需要人工核对。检查不是操作系统级锁；不要在同一时刻由多个程序改写接入配置。


### 是否需要输入令牌？

正常安装与双击启动无需填写。启动器自动使用本机凭据申请一次性连接票据，网页只在内存中持有连接凭据。直接打开网址或刷新普通浏览器页面后，重新双击 `Guardian.vbs` 即可连接；原生悬浮球和详情窗口可自动重新取得连接票据，并提供重连按钮。手动令牌输入仅保留在高级排查选项中；它不是云端模型 API 密钥。不要把 `.local` 目录发给别人。
