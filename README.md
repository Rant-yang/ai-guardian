# Agent 安全卫士（暂名）

Windows 优先的本地 Agent 行动监督预览版：汇聚工具调用、规则检查和执行回执，用透明桌面悬浮球展示活动，在告警、待审批或拒绝决定出现时弹出提示。

目前保持本地迭代，尚未公开发布。悬浮球的日常轨道动画是装饰；动作抽取与风险提示由事件驱动。没有告警不等于所有行为安全：还需要确认客户端已接入、服务在线及实际覆盖范围。

完整要求与当前差距见[原始目标核对](docs/goal-status.md)。默认语义防护、统一原窗口定位和新机器验收尚未完成。

本机体验可按[关键流程验收](docs/user-acceptance.md)进行：用独立假数据目录检查普通对话接入、保护模式和返回原会话，并按简短格式反馈。不需要对业务文件制造风险。

朋友小范围试用请先看 [10 分钟试用指南](TRIAL.md)。遇到问题可双击 `Feedback.cmd` 生成不含事件、日志和配置正文的本地诊断报告，自行查看后发送。

## 首次安装

需要 Windows、PATH 中的 Python 3.11–3.13、Microsoft Edge WebView2 Runtime。取得项目并解压后，**双击 `Install.cmd`** 即可开始安装。也可以在项目目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
```

安装完成会自动连接控制台，**不需要手动输入管理令牌或模型 API 密钥**。脚本检查依赖，在项目 `.venv` 内安装桌面依赖，再打开控制台；不会自动改动 Agent 配置。首次依赖安装需要网络，重复运行会复用已就绪的环境。缺少 WebView2 时会提供官方安装地址，由用户安装后重试。可用 `-CheckOnly` 只检查前置条件（不验证完整安装），或 `-NoOpen` 安装后不启动。

安装中断后可重新运行同一条命令：残缺的项目 Python 环境会原地修复，缺失的 pip 从 Python 自带组件恢复，不删除原目录。恢复仍需 PATH 中有可用的 Python 3.11–3.13；网络或依赖安装失败会明确报错。多个安装进程不会同时修改同一项目环境；等待超时后可稍后重试。

在控制台点击扫描，勾选需要接入的客户端，选择“预览全局接入”，核对文件路径后确认。现有文件修改前备份；保留其他插件、模型、API 和权限配置。已有接入和模式保留，新客户端默认观察模式。配置发生变化或计划超过五分钟，需要重新预览。

按客户端提示完成信任确认、重启，然后在普通对话中做一次无害读取，检查 Live 事件与回执。配置完成只代表接入文件已写入，不能代替真实行为验证。撤销时勾选客户端，预览撤销并确认，只移除本项目拥有的接入项。

现有本地用户继续双击 `Guardian.vbs`；无需为这次更新重新安装。桌面悬浮球使用 `Guardian-Overlay.vbs`，也可从控制台打开。首次安装流程仍需在干净 Windows 环境完整验收。

## 接入范围

| 客户端 | 接入方式 | 当前边界 |
| --- | --- | --- |
| Claude Code | 用户级工具前后 Hooks | 原生确认与拒绝；仍受客户端版本、信任和启用状态影响 |
| OpenCode | 用户级插件 | 普通窗口和多会话汇聚；待审批动作需要授权后重新发起 |
| Codex | 原生 PreToolUse / PostToolUse Hooks | 需要支持 Hooks 的版本及客户端信任；本机用户已反馈监督可用，不能外推到所有版本 |
| Gemini CLI | BeforeTool Hook | 本机 0.66.0 真实 CLI 合成读取/拒绝通过；尚无关联执行回执，日常会话覆盖仍待验收 |
| Qoder CLI（实验） | 工具前后 Hooks | 已修复本机启动 Shell 兼容问题；真实会话完整验收、自动返回原窗口尚未完成 |
| Pi Coding Agent（实验） | 原生扩展 | 已有隔离 CLI/RPC 执行验证；实际终端体验及来源窗口仍需验证 |

扫描仅识别已适配的客户端及相关本地线索，不承诺发现所有 Agent。Ollama 是模型服务，不是工具动作监督入口；已提供可选的[本地脱敏摘要复核](docs/local-review.md)，不改变规则和审批。另有默认关闭的[执行前语义实验通道](docs/semantic-evaluation.md)，尚不具备默认启用的效果和延迟证据；内部探针与云端复核尚未串入主判定流程。Codex 合成 MCP 演示与原生 Hooks 是不同入口。

## 观察、保护和人工介入

观察模式记录风险，不要求客户端阻止动作。保护模式在支持的执行前接口发送拒绝或审批决定；不同客户端支持程度不同。单次授权绑定客户端、会话、工具和参数，有有效期，参数改变必须重新检查；不会自动重放动作。详情区分别展示判定、授权及已收到的执行回执，未收到回执不宣称执行成功。

悬浮球通常只展示动效，风险出现时弹窗。“查看详情”当前打开 Guardian 对应事件，新增“定位原会话”：Codex 可请求打开对应桌面对话，更新后的 OpenCode 插件可定向请求选择会话，Claude 可尝试前置唯一关联终端（标签页仍需核对），不可用时提供手动定位；**尚未验证所有客户端的原窗口激活**，见[来源定位说明](docs/source-navigation.md)。关闭提示不是批准。详细说明见 [保护流程](docs/protection-workflow.md) 与 [桌面组件](docs/desktop-overlay.md)。

录屏前可通过控制台“录屏隐私”或悬浮球 ◒ 隐藏目标、会话和配置线索；此时审批与来源跳转入口暂停，退出后核对详情再处理。它不遮挡其他应用或透明球背后的桌面，详见 [隐私说明](docs/privacy.md)。

## 运行与验证

服务仅监听回环地址，默认端口 8765。日常启动器复用健康服务；不安装登录自启动。日志和本地状态位于 `.local`，其中令牌、数据库及备份不应上传。适配器使用 `access-token`；控制台使用独立的 `admin-token`，上报凭据无审批和配置权限。令牌拆分升级后重新双击启动器连接即可，钩子无需重装。主服务只使用 Python 标准库，桌面依赖见 `requirements-desktop.txt`。

同时双击启动器会串行检查并复用同一后台。端口被其他服务或另一份项目占用时，启动器会明确报错，不自动停止对方；请从原项目目录打开已有 Guardian，或先自行处理端口冲突。控制台的“本机记录管理”提供脱敏导出与确认清理；清理同时移除相关单次授权，但不会撤销已执行动作，也不是磁盘安全擦除。

```powershell
python -m unittest discover -s tests -q
node --test tests/dashboard.test.cjs tests/viz.test.cjs
```

测试覆盖规则、审批绑定、接入合并/撤销、配置变更检测、接口认证、前端交互和动画几何。自动化通过不代表所有真实客户端已完成端到端验收。

规则目前是小规模启发式规则库，存在误报、漏报和工具覆盖缺口；同一系统用户的恶意进程不在强隔离保证范围。默认无遥测或云端检测调用。后续发布门槛见 [发布准备清单](docs/release-readiness.md)。品牌与许可证仍待确定。

## 修复、更新和退出使用

桌面打不开时，双击 **`Check.cmd`**，无需启动 Guardian 后台即可检查六种客户端的接入配置；它不执行 Hook，不输出 API 密钥，也不把配置存在当成监督已生效。安装依赖不完整时重新运行 `Install.cmd`。

退出使用时，先保存并退出 Agent，再双击 **`Disconnect.cmd`**。检查列出的路径，输入 `REMOVE` 才撤销当前安装拥有的接入。冲突项保留并单独报告；本地记录、模型与聊天数据不会删除。随后关闭 Guardian 窗口，运行 `scripts/stop-background.ps1` 停止后台，并重启 Agent 验证普通读写。

**不要直接删除或移动已接入的项目目录。** 更新、迁移及完整移除步骤见[维护指南](docs/maintenance.md)。维护入口仍需可用的 Python；它不是无依赖卸载器，也不清理其他安装目录或项目级接入。
